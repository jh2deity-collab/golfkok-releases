# GolfKok (골프콕)

> 별도의 API 키 없이 클럽·구질 문제별로 YouTube 골프 레슨 영상을 바로 검색하고, 클럽별 즐겨찾기로 모아볼 수 있는 Windows 데스크톱 앱입니다.

## 다운로드

Windows용 설치 파일을 내려받아 실행하세요. (Python 설치나 관리자 권한이 필요하지 않습니다.)

👉 **[GolfKok v1.0.0 다운로드 (GolfKok-Setup-1.0.0.exe)](https://github.com/jh2deity-collab/golfkok-releases/releases/latest)**

## 설치 및 실행 방법

1. 위 링크에서 **`GolfKok-Setup-1.0.0.exe`** 를 내려받습니다.
2. 설치 파일을 실행하고 안내에 따라 설치를 완료합니다.
   - Windows Defender SmartScreen 경고가 뜨는 경우, **추가 정보 → 실행**을 눌러 진행하세요.
3. 설치가 끝나면 **GolfKok**이 자동으로 실행되며 브라우저에서 앱 화면이 열립니다.
4. 사용을 마치면 브라우저 탭을 닫아 주세요. 로컬 서버도 자동으로 종료됩니다.

## 주요 기능

- **API 키 없는 YouTube 레슨 검색**: 복잡한 키 발급이나 할당량 제한 없이 바로 검색
- **클럽·문제별 맞춤 검색**: 드라이버, 우드, 유틸리티, 아이언, 웨지, 퍼터별 문제(슬라이스, 훅, 뒤땅, 탑볼 등)와 추가 키워드, 원클릭 빠른 검색 지원
- **정렬 & 영상 길이 필터**:
  - 정렬: 관련도순 / 조회수순 / 최신순
  - 길이: 3~20분(추천) / 전체(쇼츠 포함) / 3분 미만 / 쇼츠만 보기 / 20분 이상
- **앱 내 플레이어 & 클럽별 즐겨찾기**: 검색 결과를 바로 재생하고, 마음에 드는 레슨을 클럽별로 분류 저장

## 시스템 요구 사항

- Windows 10 / 11 (64-bit)
- 인터넷 연결 (YouTube 검색 및 영상 재생용)
